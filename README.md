# BMW test Drive website
## Use Case
My BMW Test Drive System is intended to help BMW customers and car enthusiasts View available BMW models and Book a test drive, Users can select a BMW model, View its details, choose a preferred date and time, and submit their information to request a test drive. The system will provide a confirmation of the booking, If the user is under the legal driving age, a professional BMW driver can accompany them during the test drive.
## Features Excluded
-Payment or deposit handling
-Ratings and reviews
-Mobile application

## Technical Design

The BMW Test Drive Booking App uses Django's Model–View–Template (MVT) architecture.

The system includes vehicle management, test-drive bookings, booking validation, and customer and administrator roles.

**Technology stack:** Python, Django, HTML, CSS and SQLite.
